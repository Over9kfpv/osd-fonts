# CC0 collection

Bitmap fonts from [OpenGameArt](https://opengameart.org/), all released under
**CC0 1.0** (public domain). You can use, change and share them without asking and without credit,
though crediting the authors is kind.

## Left out
- **Duplicates:** re-downloads, the GrafX2 PNGs that repeat a BDF, the KenPixel "square" variants
  (10–13 % of pixels differ from the round ones), the gnsh recolours, Squont8 (already in `vault/`).
- **Too big for a 12×18 cell:** Onix fantasy font (16×17), Fugly, Pixtile, GrafX2 fight16.
- **Can't be sliced reliably:** proportional strips without a cell grid (Good Neighbors, handirt,
  Font.bmp, label font, GrafX2 Berlin/Moscow/Paris/Ruthenia/NeoSans/BitScript/Kronos), the GrafX2
  4x8/5x8/5x10 mono strips, 8x8font.gif (non-ASCII order), PA5 (loose files, unknown order),
  segment and LED displays, Jelly and lowerscript.
- **Unreadable on the OSD:** SaikyoBlack (gradient), Solar outline, KenPixel Blocks, Yandere (no clean pixel size).

A font made on the site from these letters still uses Betaflight's icons (GPL-3.0) for the symbols.
